# Sicherheitsrichtlinie

## Unterstützte Versionen

Derzeit wird nur die aktuellste Version des Projekts unterstützt.

## Meldung von Sicherheitslücken

Wenn du eine Schwachstelle in diesem Projekt entdeckst, melde sie bitte 
vertraulich, indem du uns per E-Mail kontaktierst:

**[github-email@example.com]**

Bitte gib möglichst viele Details zur gefundenen Schwachstelle an, einschließlich:

- Beschreibung des Problems
- Schritte zur Reproduktion
- Betroffene Version (falls bekannt)
- Vorschläge zur Behebung (optional)

Wir bestätigen den Eingang innerhalb von 72 Stunden und bemühen uns, das Problem 
zügig zu analysieren und zu beheben.

**Bitte veröffentliche keine Sicherheitslücken öffentlich, bevor ein Fix 
bereitgestellt wurde.**

Vielen Dank für deine Hilfe beim Schutz dieses Projekts!
