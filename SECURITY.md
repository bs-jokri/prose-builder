# 🔐 Security Policy

## Supported Versions

Only the latest version of *Prose Builder* is supported with security updates.

---

## Reporting a Vulnerability

If you discover a security issue, *please do NOT create a public issue*.  
Instead, report it privately by contacting:

📧 *your-email@example.com*  
(Replace with your real email if applicable)

Please include:

- A clear description of the vulnerability
- Steps to reproduce (if possible)
- Potential impact
- Suggested fix (if any)

---

## Our Process

1. We confirm and evaluate the issue
2. We prepare a fix and notify affected parties if needed
3. We release a patch and disclose the issue responsibly
