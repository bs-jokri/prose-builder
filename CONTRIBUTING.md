# 🤝 Contributing to Prose Builder

Thanks for your interest in contributing to *Prose Builder*!

## ✅ Getting Started (Contribution Workflow)
1. Fork this repository 
2. Clone your fork
3. Create a branch: git checkout -b feature/my-feature

## 🌱 Branching & Commits
- Branch names: feature/<name>, fix/<name>
- Commit messages should be short and meaningful:

## 🐞 Opening Issues or PRs
- Please describe your problem or feature request clearly.
- Reference related issue numbers in your pull request.
- Always create a pull request from a feature branch (not from main).

## 🧪 Testing Requirements
- Add unit tests for any new functionality.
- Make sure all tests pass before submitting a pull request.

## 🔧 Tooling Setup
- This project uses *Java* with *Maven*.
- To build and run tests locally:
  ```bash
  mvn clean install
