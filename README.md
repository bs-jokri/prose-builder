# Prose Builder

A simple library for constructing text content from individual sentences.

## Overview
Prose Builder lets you build text by registering and combining sentences in a flexible way.  
It provides an easy-to-use interface to create structured prose programmatically.

## Features
- Build text content by registering individual sentences.
- Handles line breaks automatically between sentences.
- Simple interface-based design using `Prose` and `Sentence` interfaces.
- Easy to extend with custom sentence types or builders.
