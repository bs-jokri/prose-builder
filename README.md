# prose-builder

Dies ist ein Fork des Originalprojekts *prose-builder* von [bs-jokri](https://github.com/bs-jokri/prose-builder).

In diesem Repository werden Textbausteine (Sentences und Prose) erstellt, verarbeitet und erweitert. Ziel ist es, durch die Nutzung dieser Interfaces gemeinsam an Geschichten zu arbeiten und dabei einfache Verarbeitungsschritte in Java umzusetzen.
